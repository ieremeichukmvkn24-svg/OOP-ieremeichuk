# Лабораторна №17 — Обробка I/O та мережевих помилок, Retry

**Варіант 9**, C#/.NET 10, робота з даними проєкту.

Створено асинхронну політику повторних спроб `RetryPolicy.ExecuteAsync`, підтримку `CancellationToken`, обмеження кількості спроб і exponential backoff. Повторюються тільки тимчасові помилки `IOException`, `HttpRequestException`, `TimeoutException`; відсутність файла не запускає Retry. Помилки мережі та зайнятості файла спеціально імітуються, тому приклад можна повторювати без стороннього сервера.

## Запуск
```bash
dotnet run --project lab17v9
dotnet run --project lab17v9 -- --test
```

## Висновок
Під час лабораторної роботи я навчився розділяти тимчасові й постійні помилки, обробляти винятки, обмежувати кількість повторних спроб і використовувати асинхронну політику Retry.
