# Лабораторна №15 — LINQ: фільтрація, join, агрегації, продуктивність
**Варіант:** 9. **Технології:** C#, .NET 10. **Сутність:** Project (продовження попередніх лабораторних).

Використані `Where`, `OrderBy`, `Join`, `GroupJoin`, `GroupBy`, `Sum`, `Count`, `Stopwatch`. Демонстрація фільтрів, об'єднання проєктів із власниками та журналом робіт, групування за власником, порівняння LINQ і циклу.

Запуск із кореня репозиторію:
```bash
dotnet run --project lab15v9
dotnet run --project lab15v9 -- --test
```
**Висновок:** Я навчився використовувати LINQ для фільтрації, об'єднання та групування даних і порівнювати підходи до їх обробки.
