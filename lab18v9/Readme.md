# Лабораторна №18 — Власні винятки та патерн Result

**Варіант 9**, C#/.NET 10. Сутність `Project`.

Створено власні винятки `ProjectValidationException`, `ProjectConflictException`, `ProjectNotFoundException`, похідні від `ProjectDomainException`. Впроваджено `Result<T>` та `DomainError`, що дозволяють обробляти очікувані помилки без використання винятків на рівні викликача. Продемонстровано створення, пошук і оновлення проєктів, перевірки валідності й конфліктів.

## Запуск
```bash
dotnet run --project lab18v9
dotnet run --project lab18v9 -- --test
```

## Висновок
Під час лабораторної роботи я реалізував власні типи винятків і патерн Result, навчився відрізняти очікувані помилки предметної області від неочікуваних збоїв і обробляти їх у сервісі.
